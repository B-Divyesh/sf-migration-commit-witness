01 / why

A successful command can leave the wrong tables.

The sample command returns 0 after creating one of two required tables. The CLI records the failed check and then tests rollback.

exit0≠pass

04 / limits

What it never does

  • It does not choose a production target.A test environment label, confirmation flag, and URL-name checks are required.
  • It does not invent a rollback.Rollback runs only when the config and command flag both request it.
  • It does not retain database secrets.Database URLs and signing keys are omitted from witness files.
  • It does not replace your migration tool.The config names the exact command your team already reviews.

05 / install

Run the sample, then add your config.

Build the Rust binary from source. The demo needs no config, account, or database setup.

Install version 0.1.1

cargo install --git https://github.com/B-Divyesh/sf-migration-commit-witness --bin mcw

Run the isolated sample

mcw demo

Test target checks

Confirm before any command runs

The CLI accepts test, ci, development, or ephemeral. It also requires --confirm-test-database.
